Before you begin

Sign in with a GitHub token

This page has no data of its own. It reads and edits your data repo directly, and keeps the token in this browser only.

  1. Open github.com/settings/personal-access-tokens/new.
  2. Repository access: only this repo.
  3. Permissions: Contents and Actions, both Read and write. The Kindle can use the same token.
  4. Generate it, copy it and paste it below.

Pages on the Kindle

    Tick a page to show it on the Kindle. Drag the dots to change the order.

      Preview

      Each change is saved to the repo, which rebuilds the Kindle's data in about 20 seconds. The Kindle picks it up at its next refresh.
