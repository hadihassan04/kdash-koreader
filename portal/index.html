Before you begin

Sign in with a GitHub token

This page has no data of its own. It reads and edits your data repo directly, and keeps the repo name and token in this browser only.

  1. Open github.com/settings/personal-access-tokens/new.
  2. Repository access: only your data repo (the one made from the generator).
  3. Permissions: Contents and Actions, both Read and write. The Kindle can use the same token.
  4. Generate, copy, and paste it below.
